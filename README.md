# Nutrition Slim – React Website

A React + Vite starter based on the public structure/content of the Nutrition Slim website.

## Included pages
- Home
- Product
- About
- Contact
- Privacy Policy
- Terms & Conditions

## Included components
- Responsive Navbar
- Footer
- SectionTitle
- Reusable buttons/cards
- WhatsApp inquiry form
- Responsive mobile layout

## Run
```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Important
The image areas are intentionally placeholders so you can replace them with the real product/doctor/brand images you own or have permission to use. Review all medical, product, pricing, delivery, privacy and legal claims before publishing.
